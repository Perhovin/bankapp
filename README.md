# BankApp

A C# console application demonstrating object-oriented programming concepts including classes, properties with validation, encapsulation, and exception handling.

## Features

- **BankAccount Class**: Supports account initialization, deposits, withdrawals, and positive balance checks.
- **Validation & Encapsulation**: Guards account name and non-negative balance constraints.
- **Error Handling**: Catches and reports invalid arguments gracefully.
- **Target Framework**: .NET 10.0
